## 已确认的设置

### 时间 PDE 可统一复用的基础设置

以下时间相关 PDE 当前统一使用相同的训练点数量：

- 1D Burgers
- 1D Allen-Cahn
- 1D Diffusion-Reaction
- 1D Advection-Diffusion
- 1D Advection（Discontinuous）

当前统一设置为：

```text
Nr  = 25600  # 残差点
Nbc = 256    # 每侧边界点
Nic = 512    # 初始点
```

当前统一使用 modified MLP backbone：

```text
depth = 6
width = 128
```

其他当前统一复用的设置：

```text
activation     = tanh
initializer    = Xavier/Glorot normal
precision      = float64
initial_lr     = 0.001
sampling       = LHS
```

学习率衰减和总训练步数仍按各方程在论文中的专属训练调度设置。

设置来源：论文明确给出了 Diffusion-Reaction 的点数、LHS、modified MLP 和优化信息，并说明 Advection-Diffusion 的其他训练细节相同；论文还在全局训练说明中给出 `tanh`、Xavier-normal 和初始学习率 `0.001`。将上述设置统一扩展到所有时间 PDE，是当前实验设置的补充确认，不全部等同于论文各小节逐项明确写出。

对于使用左右边界损失的方程，`Nbc=256` 表示每侧 256 点，两侧共享同一组 LHS 时间坐标进行对称采样。1D Allen-Cahn 使用周期 Fourier 映射严格满足边界条件，因此训练损失中不单独计算边界损失。

### 1D Helmholtz

- \(q=-(20\pi)^2=-400\pi^2\)。
- 严格采用 PDF Eq. 12：\(-u_{xx}+qu=f\)。
- 解析解为 \(u(x)=\sin(20\pi x)\)，代入后 \(f=0\)。
- 该齐次方程只配合两端零边界时不是唯一解，\(u=0\) 和任意 \(A\sin(20\pi x)\) 都满足方程。
- 当前新增内部观测条件 \(u(1/40)=1\)，将振幅固定为 \(A=1\)，从而排除零解。
- 内部观测作为独立 PointSetBC，损失权重为 100。
- 该条件用于解决非唯一性，但不是 PDF 论文中打印的原始条件；新的运行结果必须与旧的无观测结果分目录保存。

### 2D Poisson（Peak）

- 完整解析解为

  \[
  u(x,y)=2^{4a}x^a(1-x)^a y^a(1-y)^a,\qquad a=10.
  \]

### L-Shaped Poisson

- 方程为 \(-\Delta u=1\)，区域为 \([-1,1]^2\setminus[0,1]^2\)，完整边界上 \(u=0\)。
- 论文设置为 `Nr=10000`、`Nbc=8×128=1024`，采用 LHS。
- 论文给出的损失权重为 `wr=1`、`wb=100`，并在 DASA 中设置 `NS1=5000`、`NS2=2000`、`NS3=NS4=10000`，随后使用 L-BFGS 1000 步。
- 当前 classical PINN 将论文的 `NS3+NS4` 映射为一个 20000 步的标准 Adam 阶段，不包含 DASA 专属的 `NS1/NS2`；论文没有单独写出 classical PINN 的训练步数。
- 当前 backbone 采用 modified MLP `depth=6`、`width=128`，以满足论文 Table 2 所述 classical PINN 与 DASA 使用相同 architecture 和 hyper-parameters；L-shaped 小节本身没有再次单独列出网络规模。
- 论文参考解由 FEALPy 自适应 FEM 生成；当前环境没有 FEALPy，因此当前项目使用本地高分辨率五点有限差分参考场。
